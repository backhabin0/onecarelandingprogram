# 대량 등록 예시 파일

`npm run samples`로 다시 만들 수 있다(`scripts/generate-samples.ts`). 관리자 화면과 같은 함수로 만들므로 실제 결과와 같다.

| 파일 | 내용 |
| --- | --- |
| `onecare-bulk-upload-template.xlsx` | "AI 대량 생성" 화면의 **엑셀 양식 다운로드**와 같은 파일. 첫 줄 머리글 29칸 + 예시 1행(모든 칸 텍스트 형식). 맨 뒤 4칸이 사진2·사진2 설명·사진3·사진3 설명(사진 기능에서 추가, 이전 25칸 양식도 그대로 올릴 수 있음) |
| `prompt-3regions-x-2keywords.txt` | **프롬프트 만들기** 탭 결과 예시. 지역 3개 × 키워드 2개 = 6행(사진 보관함이 비어 있을 때) |
| `prompt-with-photos.txt` | 같은 값으로, 사진 보관함에 사진 4장(`배관내시경.jpg` 등, 이름·설명)이 있을 때. 사진 목록과 "내용에 맞는 사진을 골라 사진 칸에 파일 이름으로, 같은 사진이 몰리지 않게" 규칙이 들어간다 |

프롬프트 예시에 넣은 값(프롬프트 만들기 탭에 그대로 붙여넣을 수 있음):

- 지역 목록
  ```
  산본동, sanbon
  금정동, geumjeong
  수리동, suri
  ```
- 키워드 목록
  ```
  배관 수리, pipe-repair
  하수구 막힘, drain-unblocking
  ```
- 업체명 `원케어 설비(예시)`, 전화 `010-0000-0000`(가짜 번호), 템플릿 `template-a`, 업종 설명 `배관 누수·하수구 막힘 출장 수리 서비스`

사용 순서: 프롬프트를 ChatGPT·Claude 등에 붙여넣기 → 받은 표를 "AI 대량 생성 > 올리기" 탭의 붙여넣기 칸에 넣거나 엑셀에 붙여 저장해 올리기 → 검사 결과 확인 → 대기열에 넣기.
시/군·city_slug·현장 사례 칸은 AI가 비워 두므로, 필요하면 엑셀에서 직접 채운 뒤 올린다.
사진 칸(대표 사진 URL·사진2·사진3)은 보관함에 사진이 있으면 AI가 파일 이름으로 채우고, 없으면 비워 둔다. 사진 설명 칸은 비워 두면 보관함 설명이 들어간다.
올리기 화면의 **공통 사진 설정**(로고·사진1~3)을 쓰면 사진 칸이 빈 행에만 그 사진이 들어간다(행에 있으면 행이 우선).

사진 칸(대표 사진 URL·사진2·사진3)과 선택 칸 `로고`(머리글을 넣으면 인식)에는 관리자 **사진 보관함**에 올린 사진의 이름(예: `현장1.jpg`, 확장자는 생략 가능) 또는 http(s) 주소를 쓴다. 보관함에 없는 이름은 검사에서 오류로 표시되고 그 행은 대기열에 들어가지 않는다. 같은 사진을 여러 행에 써도 파일은 하나만 저장된다.
