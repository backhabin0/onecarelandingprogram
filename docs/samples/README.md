# 대량 등록 예시 파일

`npm run samples`로 다시 만들 수 있다(`scripts/generate-samples.ts`). 관리자 화면과 같은 함수로 만들므로 실제 결과와 같다.

| 파일 | 내용 |
| --- | --- |
| `onecare-bulk-upload-template.xlsx` | "AI 대량 생성" 화면의 **엑셀 양식 다운로드**와 같은 파일. 첫 줄 머리글 25칸 + 예시 1행(모든 칸 텍스트 형식) |
| `prompt-3regions-x-2keywords.txt` | **프롬프트 만들기** 탭 결과 예시. 지역 3개 × 키워드 2개 = 6행 |

프롬프트 예시에 넣은 값(프롬프트 만들기 탭에 그대로 붙여넣을 수 있음):

- 지역 목록
  ```
  산본동, sanbon
  금정동, geumjeong
  수리동, suri
  ```
- 키워드 목록
  ```
  배관 수리, pipe-repair
  하수구 막힘, drain-unblocking
  ```
- 업체명 `원케어 설비(예시)`, 전화 `010-0000-0000`(가짜 번호), 템플릿 `template-a`, 업종 설명 `배관 누수·하수구 막힘 출장 수리 서비스`

사용 순서: 프롬프트를 ChatGPT·Claude 등에 붙여넣기 → 받은 표를 "AI 대량 생성 > 올리기" 탭의 붙여넣기 칸에 넣거나 엑셀에 붙여 저장해 올리기 → 검사 결과 확인 → 대기열에 넣기.
시/군·city_slug·대표 사진 URL·사진 설명·현장 사례 칸은 AI가 비워 두므로, 필요하면 엑셀에서 직접 채운 뒤 올린다.
